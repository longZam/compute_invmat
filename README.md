# 역행렬 계산기
.NET C#으로 작성한 역행렬 계산기입니다. 입력받은 행렬에 대해 행렬식과 가우스 조던 소거법을 이용해 역행렬을 구합니다.

## 사전 요구 사항
이 프로젝트를 빌드하고 실행하려면 시스템에 .NET SDK가 설치되어 있어야 합니다.

## 프로젝트 빌드 및 실행
```bash
dotnet run
```

## 참고 사항
별도의 입력 데이터 유효성 검증이 구현되지 않았습니다. 올바른 형식의 정상적인 데이터가 입력된다는 가정하에 정상적으로 작동합니다. 요구 사항에 따라, 입력되는 정방행렬의 차수는 4 이하의 자연수여야 합니다. 가우스-조던 소거법으로 계산된 역행렬은 부동소수점 연산에서 발생하는 오차의 누적으로 의해 행렬식으로 계산된 역행렬과 차이가 있을 수 있습니다.
